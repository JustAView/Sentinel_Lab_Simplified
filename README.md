# Sentinel Lab — локальный учебный файловый сканер

## Возможности
- Упрощённый интерфейс: обзор, сканер, программы, карантин и отчёты.
- Проверка файлов из папки `lab_files`, вычисление SHA-256 и поиск нескольких учебных текстовых индикаторов.
- Перемещение в карантин, восстановление, обезвреживание (содержимое заменяется безопасной текстовой заглушкой) и удаление из карантина с анимацией.
- JSON-отчёты в папке `reports`.
- Встроенные безопасные мини-приложения: браузерная оболочка, текстовый редактор, калькулятор, медиаплеер и список файлов лаборатории. Это учебные аналоги, а не копии установленных программ Windows.

## Запуск на Windows
1. Установите Python 3: https://www.python.org/downloads/ (при установке включите Add Python to PATH).
2. Распакуйте архив в отдельную папку.
3. Запустите `start.bat` и не закрывайте окно консоли, пока пользуетесь стендом.
4. Откройте `http://127.0.0.1:8765`.
5. Добавьте файлы в папку `lab_files`, затем нажмите «Начать проверку».

## Важно
- Сканер обрабатывает только `lab_files`, а не весь компьютер.
- Программы и скрипты не запускаются сканером; они читаются как данные.
- «Обезвредить» заменяет содержимое файла в карантине безопасной текстовой заглушкой; восстановить исходное содержимое после этого нельзя.
- «Удалить» окончательно удаляет выбранный файл только из папки `quarantine` внутри проекта.
- Это учебный сканер, а не замена полноценному антивирусу. Статус «чистый» не гарантирует отсутствие вредоносного кода.
- Сервер привязан к `127.0.0.1` и предназначен для локального использования.
